# Inherited license preservation

The portable new verifier uses the Python standard library only. The inherited producer-code copies document source conventions and reference python-flint; they are not a dependency installation or authorization to run new physical calculations.

The existing research packet identified the official python-flint 0.9.0 wheel aggregate license expression as MIT AND LGPL-3.0-or-later. The seven previously verified upstream notice/license texts and their recorded hash manifest are copied without modification under licenses/. These preserve the python-flint, FLINT, GMP, and MPFR license boundaries. No wheel, native library, compiled module, or third-party implementation is included.

The new CC BY-NC 4.0 scope excludes these third-party notices and all external dependencies. Retaining these notices does not claim a complete compliance review for any hypothetical binary redistribution.
