## 6. form, 정의역, 역

**닫힌 보조 form.**
- m_g = a + γ_g는 M_C의 대각성분이므로 m_g ≥ a > 0입니다. 또 m_g − ωV_full은 상수입니다.
- 양의 곱셈 form은 닫혀 있습니다. C_c^∞(Ω) ⊂ D_g이므로 조밀합니다.
- 유계 −P_B를 빼도 닫힘과 정의역이 보존되며, form은 ≥ (a+c)‖q‖²입니다.

**연산자와 역.**
- 연산자는 (최대 곱셈 연산자 m_g) − A_graph입니다. 따라서 D(A_g^op) = {V_full q ∈ L²}이고, 이는 form 정의역 D_g보다 강한 조건입니다.
- U 아래에서 A_g^op = U⁻¹M_C U입니다. T_{g,μ} = (A_g^op + μ)⁻¹은 ‖T_{g,μ}‖ ≤ 1/(a+c+μ)이며 반사와 가환합니다.

**D_g는 L²에서 닫혀 있지 않습니다.** 끝점 근방에서 |q|² = 1/(d·log²(1/d))로 잡으면 q ∈ L²이지만, V_full ~ ½log(1/d)이므로 ∫V_full|q|² = ∞입니다. 잘라낸 함수들은 L²에서 q로 수렴합니다. 따라서 Max의 반례는 유효합니다.

**V_min ⊂ D_g (비순환 증명).** Tonelli로 다음을 직접 유도했습니다.

> D(J_Ω q) = ½∬_{Ω²} ρ(|x−y|)·|q(x)−q(y)|² + ∫_Ω (R(B+x) + R(B−x))·|q|²

R(s) = ∫_s^∞ ρ이므로 ∫V_full|q|² ≤ D입니다. 그러면 Gamma-norm Cauchy 열은 L²(V_full dx)에서도 Cauchy이고, 따라서 V_min ⊂ D_g, V_high ⊂ D_g ∩ H_hi입니다.
- 최소 정의역과 최대 정의역이 같다고 가정하지 않았습니다.
- D_g = D_{p_g}는 두 보조 form 정의역 사이의 등식일 뿐입니다.
- 전공간 역과 high 제약 역(I 294–385)은 별개입니다.

## 9. 논문용 정리 (자체 완결형)

**설정과 기호.**
- B = 3/4, Ω = (−B, B). L²(Ω)는 복소이며 내적은 첫 인자에 켤레선형입니다.
- ρ(s) = e^{−s/2}/(1−e^{−2s})
- R(s) = ∫_s^∞ ρ = artanh(e^{−s/2}) + arctan(e^{−s/2})
- V(x) = R(B+x) + R(B−x), V₀ = 2R(B)
- W_B(x) = −½log(1 − x²/B²), Δ = V − V₀ − W_B
- cΓ = log π + γ_E + π/2 + 3log2
- θ = 2⁻¹⁶, ω = 1 − θ
- δ₀ = V₀ − cΓ + 5/2, j₇ = 29/5 − cΓ
- P_B(f,f) = Σ_{n=2,3,4} (Λ(n)/√n)·2Re∫_{Ω∩(Ω+log n)} f̄(x) f(x − log n) dx
- D = {f : ∫V|f|² < ∞}
- C[f] = ∫(ωV + 17ω/5 + 7θ − cΓ)|f|² − P_B(f,f)
- d̄는 §2 표의 짝수 계단함수이고, p_g = ω(W_B + 9/10 − d̄)입니다.

**정리.**
- (i) δ₀ > 0, j₇ > 0, Ω에서 Δ ≥ 0, 거의 모든 점에서 p_g ≥ 0.
- (ii) 모든 f ∈ D에 대해 C[f] ≥ ∫(p_g + ωΔ)|f|² + c_coer‖f‖², 여기서 c_coer = ωδ₀ + θj₇ > 0.
- (iii) 임의의 a > 0에 대해 a‖f‖² + C[f]는 D 위에서 조밀하고 닫혀 있으며 하계 a + c_coer를 갖습니다. 그 연산자 A는 다음을 만족합니다.
  - D(A) = {Vf ∈ L²}
  - ‖(A+μ)⁻¹‖ ≤ 1/(a + c_coer + μ) (μ ≥ 0)
  - 반사와 가환
