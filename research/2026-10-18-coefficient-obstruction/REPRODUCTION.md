# Reproduction boundaries

This distribution preserves existing numerical inputs and results. Publication performed file copying, SHA256 checks, static code review and document compilation. It did **not** run a mathematical replay, source action, integral, solve, factor or tau test.

## 1. Byte identities

From this directory:

```sh
sha256sum -c MANIFEST.sha256
```

This verifies bytes, not mathematical truth. The input hashes in INPUTS.json preserve original scientific file bytes; only their manifest paths were made relative. The original executed checker hash is recorded there. The public resource summary is an explicitly curated extract of prior accepted records, not a byte-identical replacement for private host/admission files.

## 2. Optional reader-side saved arithmetic

In a fresh working copy, with Python3.11+ standard library and a new output path:

```sh
python3 replay_saved.py --output /tmp/theta-coefficient-reader-output
```

The adapter was statically inspected but **not run during publication**. It loads the unchanged executed checker, substitutes a portable input resolver, and substitutes a direct exact211-coordinate check of the same saved witness for the original private prior-run admission. It then invokes the unchanged scalar/enclosure/residual/comparison implementation and compares its mathematical fields with the saved report.

It does not rerun the midpoint production, solve for C or v, factor a matrix, generate physical inputs, prove source premises or reconstruct the original OS/resource protocol. The diagnostic is over the selected support, with the remaining161 coordinates exactly zero. U_MODEL/UCERT retain full372 data and row pads.

The adapter's60-second cooperative elapsed guard is a reader convenience, **not** the historical external resource certificate or a hard process sandbox. Run it under appropriate independent resource controls if desired. Unsupported input, mismatch, time limit or an existing output directory stops the adapter. No automatic retry or changed parameters are supplied. Runtime success of this newly portable adapter has not been claimed.

## 3. Original run distinctions

`results/execution_summary.json` separates:

- midpoint production: actual exit2, unaccepted pivot210, no successful full factor, no independent scientific checker, resource_acceptance=false and no accepted complete timing/RSS witness;
- same-direction diagnostic: actual exit0, exact center/pad comparison, accepted external timing/resource and reap closure;
- coefficient-gap diagnostic: actual exit0, two conditional exclusions, accepted external timing/resource and reap closure.

The latter two resource results do not retroactively certify the first production attempt. The raw coefficient worker report's provisional resource flag remains untouched; external acceptance is reported separately. No total publication duration is presented as scientific compute time.

## 4. Input-generation boundary

The primitive true-source/domain/action/Gram inclusions remain inherited. A full regeneration would require the earlier source archive, its physical code and separately validated numerical environment. This package is a saved finite-arithmetic reproducibility distribution, not a hermetic physical-production environment. The mathematical assumptions and original data meanings are stated in ASSUMPTIONS.md and in the accompanying paper.
