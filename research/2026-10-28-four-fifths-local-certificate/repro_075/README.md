# Portable exact-rational certificate replay

Python 3.11+ standard library only. From this directory run:

    python verify_exact.py --data-dir data --output result.json

Do not use Python `-O`. All three unchanged proof-data files are SHA256-bound. The original diagnostic deliberately records failure of an older coarse-tail matrix; its full interval arrays are reused, not its failed positivity conclusion.

The checker reconstructs the replacement intervals using rational endpoint arithmetic, retains a hull containing both independently reconstructed and saved intervals, then verifies an exact LDL midpoint residual. It computes and explicitly checks the unit-triangular inverse. The lower bound is `min(D)/||L_inverse||_F^2 - residual_max_row_sum`. Full coupling uses the larger of the saved trace and a conservatively recomputed trace. The final rational comparison must exceed `1/10^20`.

Trust boundary: original analytical matrix/tail formulas and source interval enclosures, including the saved elementary transcendental enclosures, are inputs. No new transcendental evaluation or FLINT import occurs. This is an independent rational algebraic certificate replay, not a formal verification of all analytical dependencies or a proof of RH.

Operational receipts, approval identifiers and private launch records are deliberately not inputs. Their omission changes no mathematical check. Original-producer and saved-gate provenance hashes remain in proof metadata; this replay does not execute those producers. Resource-limit wrapper and private execution receipt are kept outside this public directory. The published `result.json` is generated by the one controlled public replay.
