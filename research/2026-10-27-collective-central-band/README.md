# Collective control of a shrinking prime spectral band

## Result and limitations

For every integer N >= ceil(exp(2^20)), write L = log N and let Omega_N be the phase-defined positive observation set in the manuscript, restricted to |xi| <= L^3. The paper proves

    A_c,N(u) <= [18432 log L / (pi L)] B_Omega,N(u) + epsilon_N N_X(u)

for every real even vector in the specified theta-weighted space X. Both the relative coefficient and the explicit epsilon_N tend to zero. The complete theta source, every prime power up to N, the exact epsilon_N, and the Fourier convention are given in the manuscript. The physical-tail rate is O(L^3 log L N^(1/2-pi)); the window error is smaller than every fixed negative power of N.

Only the shrinking central band |xi| <= 1/L is controlled. All other negative bands remain unresolved. The positive observation is spent once. A vanishing relative coefficient is not a vanishing contribution: the product of that coefficient with B_Omega,N diverges for fixed smooth test functions with nonzero Fourier value at zero. The exact signed remainder retains the pole term. There is no full-form lower bound, full signed positivity, eigenvalue exclusion, or proof of the Riemann hypothesis. The threshold is a symbolic sufficient integer, not a feasible computed prime cutoff.

The bounded observations act on all real even X. The sharp physical pieces are used only inside bounded-frequency observations; no preservation of the full minimum form domain or by hard Fourier cutoff is asserted.

## Build and arithmetic reproduction

A standard TeX Live or MiKTeX installation with the LaTeX packages named in the source is sufficient. Run from the unpacked directory:

```sh
sh build.sh
python3 reproducibility/exact_checks.py > /tmp/collective-band-checks.json
cmp /tmp/collective-band-checks.json reproducibility/exact_checks.json
sha256sum -c SHA256SUMS
```

In the release directory, `sha256sum -c RELEASE_SHA256SUMS` also verifies the ZIP itself. The outer checksum file is not included inside that ZIP.

The PDF build uses a fixed source date for metadata. Different TeX distributions, fonts, or build paths may produce different PDF bytes; the included hashes identify the exact supplied artifacts, not a promise of cross-platform byte-identical compilation. Check the supplied manifest before rebuilding if you wish to verify the original PDF bytes.

Python 3's standard library is sufficient for the checks. The script needs no source file, external dataset, network access, or third-party package. Its 30 successful assertions check only the finite arithmetic identified in their output. They do not certify the analytic proof, evaluate the theta kernel, enumerate primes, verify PNT numerically, perform quadrature, execute a spectral computation, or approximate an operator norm.

## Classical input and attribution

The prime number theorem input is Johnston and Yang, Theorem 1.1 in the exact author manuscript arXiv:2204.01980v2, printed page 2:
https://arxiv.org/pdf/2204.01980v2

This unconditional theorem incorporates finite-height computational ingredients. They are accepted through that theorem, not independently regenerated by this package. The author manuscript was inspected; the publisher's full text was unavailable for comparison.
