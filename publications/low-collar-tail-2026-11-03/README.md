The original preparation README and manifest are preserved as README.prepublication.md and SHA256SUMS.prepublication. Their review-pending text describes preparation before the independent audit. SHA256SUMS is the current publication manifest.

Run ./build.sh to compile and python3 checks/check_algebra.py with SymPy for elementary algebra checks. **The code is not a numerical sign certificate**, does not certify numerical columns, and does not prove the infinite-dimensional theorems. The result does not establish a low-window sign, full-kernel identification, or a proof/disproof of RH. The finite-rank schedule may be impractical.
